## Pitch (Short)

## Description
issuebeam is an open-source developer tool that wires any AI coding agent (Cursor, Claude Code, GitHub Copilot, Windsurf) to your official GitHub Issues. 

Instead of manually translating chat conversations into bug reports, issuebeam provides a zero-dependency Python CLI and multi-platform agent instructions. This allows your AI to autonomously list, create, comment on, and close GitHub issues without leaving the IDE or terminal. 

Perfect for developers practicing "vibe coding" who want to keep their technical debt and task management cleanly synced with GitHub. Works natively on Windows, macOS, and Linux.
