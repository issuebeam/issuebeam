## Descrizione
Developers are increasingly using AI agents like Cursor and Claude to write code faster ("vibe coding"). But project management is lagging behind: bugs and tasks discovered during coding sessions get lost in endless chat logs.

issuebeam bridges this gap. It's a completely open-source, zero-dependency CLI tool that allows any AI assistant to communicate directly with GitHub Issues. When your AI spots a bug, it can autonomously create a ticket for it. 

Easy to adopt into any repository and fully cross-platform.
