## Short Description (Pitch)
issuebeam gives your AI coding agents (like Cursor, Claude Code, and Copilot) the ability to natively interact with GitHub Issues. 

## Full Description
When developing with AI (vibe coding), technical debt, bugs, and new feature ideas often get buried and lost inside long chat contexts. 
issuebeam solves this by wiring your AI agent directly to your GitHub repository. It acts as a lightweight, zero-dependency Python bridge that allows the AI to run a CLI command to autonomously list, open, comment, and close official GitHub issues without the developer breaking their workflow.

Compatible with Windows, Mac, and Linux, and requires zero third-party dependencies.
